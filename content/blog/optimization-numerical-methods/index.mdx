## 记号约定

| 记号 | 含义 |
|---|---|
| $\min f(x)\ \ \mathrm{s.t.}\ x\in S$ | 最优化问题的标准写法，$S$ 为可行域 |
| $\nabla f$、$\nabla^2 f$ | 梯度与 Hessian 矩阵 |
| $d^k$、$\alpha_k$ | 第 $k$ 步的搜索方向与步长 |
| $f(x^k+\alpha d^k)$ | 沿方向 $d^k$ 的截线 $\phi(\alpha)$ |
| $\mathbb{R}_+^m$ | 分量非负的 $m$ 维向量 |
| $T_S(x^*)$、$F_S(x^*)$ | 切锥与线性化可行方向锥 |
| $\lambda_j$、$\mu_i$ | 不等式约束与等式约束的 Lagrange 乘子 |
| $f^*$、$d^*$ | 原问题最优值与对偶问题最优值 |

## 几条主线

- **最优性条件**：一阶必要条件 $\nabla f=0$ $\to$ 二阶必要条件（Hessian 半正定）$\to$ 二阶充分条件（Hessian 正定）
- **线搜索**：Armijo 准则（充分下降）$\to$ Wolfe 准则（再加曲率条件）$\to$ Zoutendijk 条件（收敛性前提）
- **无约束算法**：梯度下降（线性收敛）$\to$ 牛顿法（$Q$-二次收敛，但需 Hessian）$\to$ 拟牛顿法（只用一阶信息达超线性收敛）
- **对偶**：弱对偶 $d^*\le f^*$ 恒成立；Slater 条件下强对偶成立
- **约束优化**：KKT 条件 = 稳定性 + 原始可行 + 对偶可行 + 互补松弛
- **罚函数与增广 Lagrange**：二次罚函数法要求罚参数 $\to\infty$（数值病态），增广 Lagrange 乘子法通过更新乘子避免这一点
